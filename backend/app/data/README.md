## Гекс-сетка: формат `hex_edges.json`

Каждое ребро — соседство двух гексов в раскладке на `player_count` игроков:

```json
[
  {"player_count": 4, "a": 1, "b": 2, "kind": "land", "draft": false},
  {"player_count": 4, "a": 2, "b": 6, "kind": "river", "draft": false}
]
```

- `kind: "land"` — обычное соседство, проход свободный.
- `kind: "river"` — гексы разделены рекой, нужен мост (мост можно сломать/починить).

**Что нужно заполнить** (схемы в PDF — картинками, поэтому не извлечено):
1. для каждой раскладки (2/3/4) — полный список рёбер-соседств;
2. какие рёбра — `river` (и где стоят мосты).

## Как править

- Правь `.json` напрямую, затем `python -m app.seed`.
- `draft: true` — черновик, нужна сверка.
